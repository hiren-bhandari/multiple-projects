# multiple-projects

A collection of independent hobby projects. Each project lives in its own
top-level directory with its own README, dependencies and tooling.

## Projects

| Directory | What it is |
| --- | --- |
| [`tv-control/`](tv-control/) | Connect to my TV over the local network and operate it |

## Conventions

- One top-level directory per project; nothing is shared between projects unless it clearly needs to be.
- Each project is developed on its own branch (and its own git worktree when working on several at once).
